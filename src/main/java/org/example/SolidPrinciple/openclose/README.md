Open/Closed Principle (OCP)
The Open/Closed Principle is another core SOLID principle that states:

Software entities (classes, modules, functions) should be open for extension but closed for modification.

This means that:

Open for extension: You should be able to extend the behavior of a class without modifying its existing code.
Closed for modification: Once a class is developed and tested, it should not be changed to add new functionality. Instead, you should extend it.

Why OCP is Important?

Avoids introducing new bugs by modifying existing code.
Makes the code more maintainable and scalable.
Encourages the use of abstraction and polymorphism.
Real-World Analogy
Think of a power socket.

The wall socket (existing code) doesn't change.
When new devices are introduced (extension), we use different adapters without modifying the socket itself.
